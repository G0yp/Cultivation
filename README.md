- Sect building
- Idle cultivation
- Joining sects and getting bonuses

- Immortality / Reset Layers / Reincarnation
- Skills and Abilities
- Shops

- Cultivation Manuals / Skill Manuals
- Blacksmithing
- Tailoring
- Numbered Skill System?
