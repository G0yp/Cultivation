# Cultivation
Repo for Xianxia game collaboration

# Ideas
- Isometric/topdown (like necesse?) graphics
- Start in a town
- Tiled sort of world map with different towns/wild areas
- Sect building
- Idle cultivation
- Joining sects and getting bonuses
- Semi open world (thinking like gen 4 Pokemon Platinum. Open world with gated progression)
- Procedurally generated dungeons (common) or inheritances (rare)


# Engine
Godot or Unity

## Godot
- simpler
- open source
- completely free
- lightweight
- first class Linux support
- GDscript (Python), C#, and C++ support
